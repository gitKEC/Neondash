# Neon Dash

Jeu d'arcade mobile : une boule néon file sur une piste, glisse ton doigt pour esquiver les murs. La vitesse augmente sans cesse.

- 4 mondes (Néon City, Abysses, Volcan, Galaxie), 20 niveaux avec arrivée et étoiles, et un mode Infini au décor évolutif
- Obstacles variés (murs à trou, doubles passages, zigzags, piliers, blocs mobiles, portes, rotors), toujours franchissables
- Gemmes à ramasser, bonus Bouclier et Ralenti, bonus « frôlé »
- 6 skins à débloquer avec les gemmes, meilleur score sauvegardé
- Classement entre amis (Infini et étoiles) avec pseudo — nécessite une base Upstash Redis gratuite connectée au projet Vercel
- Musique et effets sonores synthétisés, pause automatique
- Installable sur l'écran d'accueil (Safari → Partager → Sur l'écran d'accueil), mise à jour automatique
